SWARM · FIRST LAUNCH
BEFORE STEP 1 · Device setup

Set up your user account.

Swarm needs a non-root account to keep your work separate from system administration.

A new name creates a user account and home folder. An existing name uses that account without changing its password. No administrator access is granted.

Your account is ready. Would you like to set a login password?

Skip keeps password login disabled. It does not allow blank-password login.
Your password is handed directly to the OS. Swarm does not save it.

Would you like to add an SSH key?

Continue to enter a public key for SSH access, or skip this step. Skipping leaves SSH keys unchanged.
Only one plain ssh-ed25519 public key is supported. Never paste a private key. Installing a key does not verify SSH login or reachability.
