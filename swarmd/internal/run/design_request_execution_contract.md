# Independent Designer execution

`manage_design` accepts briefs and authorized immutable context through `ApplySessionMutation(design.accept)`. Acceptance wakes the daemon-owned `DesignDispatcher`; bounded durable discovery repairs missed hints and startup. Parent completion does not cancel accepted work. Two local workers bound dispatch, while permission-owned aggregate `AdmitExecution` remains authoritative.

`AllocateDesignChild` resolves account Designer settings (or explicitly alerted account default), then atomically creates the child, canonical pending run and attempt binding. Recovery returns no admission lease. Dispatch changes pending to running through canonical event-sequence CAS before making exactly one provider adapter call. There is no provider retry. A bound attempt without a live dispatcher owner is conservatively interrupted on recovery, even if its intent was pending, unless exact retained output already has successful immutable validation evidence.

Provider requests contain fresh isolated context, configured model/thinking, objective, output kind, actual immutable source text with paths/digests/ranges, and exact retained edit/plan bytes. There are no tools, invoker, workspace grants, Artifact V3 grants, Git, Parts, or publication capabilities. A plan returns text only. HTML must be a complete document and pass the daemon-owned standalone sandbox renderer. The renderer uses the canonical cache root, no application credentials and no external network grants; absence fails closed. Plans skip the renderer. Automated renderability is not aesthetic verification.

Each attempt has a three-minute context deadline; a candidate has a ten-minute total budget, token cap and streamed/final byte bounds. Returned bounded bytes and provider token receipts are retained before validation, including failed/cancelled returns. Output beyond the durable byte limit is rejected rather than truncated into misleading evidence. Safe allowlisted content diagnostics permit at most two repairs, each a new canonical child/run with fresh provider context/cache/lineage. Repairs include the original objective, immutable sources, exact base/plan inputs, full bounded failed bytes, failed output reference and safe diagnostic code. Previous leases are released before new admission. Provider errors, infrastructure errors, cancellation, timeout and uncertain restart never cause provider replay. Failed/exhausted candidates are not rediscovered as queued work. Shutdown cancels and joins workers before store closure; adapters must honor cancellation. Cancel-requested history blocks publication unless canonical completion already won the race. Dispatch rechecks cancellation before submission. Cancellation between a failed attempt and repair admission fences the next child while retaining the original failure receipt. Terminal canonical run observations precede independent immutable result publication. Sibling request-revision CAS conflicts retry persistence only, never provider calls. Successful siblings remain retained and metadata-only history avoids returning full HTML by default.

Queue repair runs every five seconds in addition to acceptance/cancellation/completion hints. Each wake processes at most one 256-position page, retaining a global continuation; owner-scoped seeks skip historical key families to reach pending indexes without reading their contents. Errors remain discoverable in durable pending state; diagnostics do not include provider/source contents. Desktop consumes the independent session design catalog and `design.accepted`/`design.updated` events, with initial/reconnect hydration rather than polling. Its gallery previews stored sandbox PNG captures (not interactive authored HTML), displays plan text and immutable parentage, downloads exact bytes, and separates revision navigation from selection CAS. Historical edits enqueue an authenticated canonical parent user message carrying the exact base and brief; the parent submits through `manage_design`, without authoring or publishing HTML. See `../api/design_api_contract.md`. Existing Artifact V3 read/edit routes remain separate; no generated design is automatically integrated into source code. Session-local catalog indexing starts with this unreleased contract; pre-index development records require explicit backfill, not a hidden scan. A crash after response retention but before validation interrupts honestly without provider replay. Persisted successful validation permits idempotent publication across canonical-completion/publication crash windows; a completed intent without retained validated output still interrupts with `completed_output_unavailable`. Recovery never fabricates output or repeats generation; successful siblings and previously selected revisions remain unchanged. Preview references bind the exact output digest and retained PNG. Browser errors are mapped to fixed codes without logging raw provider/browser payloads.

Both direct and provider-managed tool paths bind a separate canonical pending sensitive-read permission for every source file, including innocent filenames. Missing or mismatched principal/session/run/scope fails closed before acceptance. Stable unavailable-model/allocation outcomes terminate queued candidates with a visible reason and RouterAlert, without fabricating a child or attempt; transient admission/CAS errors remain retryable.
