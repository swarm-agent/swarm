# Independent Designer execution

`manage_design` accepts briefs and authorized immutable context through `ApplySessionMutation(design.accept)`. Acceptance wakes the daemon-owned `DesignDispatcher`; bounded durable discovery repairs missed hints and startup. Parent completion does not cancel accepted work. Two local workers bound dispatch, while permission-owned aggregate `AdmitExecution` remains authoritative.

`AllocateDesignChild` resolves account Designer settings (or explicitly alerted account default), then atomically creates the child, canonical pending run and attempt binding. Recovery returns no admission lease. Dispatch changes pending to running through canonical event-sequence CAS before making exactly one provider adapter call. There is no provider retry. A bound attempt without a live dispatcher owner is conservatively interrupted on recovery, even if its intent was pending.

Provider requests contain fresh isolated context, configured model/thinking, objective, output kind, actual immutable source text with paths/digests/ranges, and exact retained edit/plan bytes. There are no tools, invoker, workspace grants, Artifact V3 grants, Git, Parts, or publication capabilities. A plan returns text only. HTML must be a complete document; this structural check is not browser/safety validation.

Provider calls have a ten-minute context deadline, token cap and streamed/final byte bounds. Shutdown cancels and joins workers before store closure; adapters must honor cancellation. Cancel-requested history blocks publication. Terminal canonical run observations precede independent immutable result publication. Sibling request-revision CAS conflicts retry persistence only, never provider calls. Successful siblings remain retained and metadata-only history avoids returning full HTML by default.

Queue repair runs every five seconds in addition to acceptance/cancellation/completion hints. Errors remain discoverable in durable pending state; diagnostics do not include provider/source contents. Browser validation, rendering, repair and Desktop UI remain deferred. Crash after canonical completion but before independent publication conservatively interrupts the observation rather than replaying generation or claiming retained success.
